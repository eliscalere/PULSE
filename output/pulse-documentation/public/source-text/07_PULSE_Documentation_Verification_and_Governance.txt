The current package uses the active implementation and current application labels first.
Historical references are retained only when they remain consistent with the current source.

  1        Active implementation. The SharePoint Framework web part renders LegacyWorkspaceFrame, which embeds the generated browser
           application sourced from apps/PULSE.


  2        Current browser source. apps/PULSE/index.html defines the active module order and current visible interface labels.

0 6 / G OV E R N A N C E D E C I S I O N S




Seven decisions remain outside the
code
These questions require an authoritative organizational answer. The application and
repository cannot establish policy by themselves.

01         Deployment authority
           Which office authorizes production deployment and rollback of a PULSE package?



02         Records retention
           What retention periods apply to project, meeting, travel, formal review, ticket, notification, and activity records?



03         Classification and handling
           Which markings, handling restrictions, and approved storage locations apply to each record type and generated PowerPoint file?



04         Travel evidence
           What evidence is required for travel approval, finance approval, denial, revocation, and cancellation?



05         Role authority
           Which roles may create, edit, archive, restore, export, or delete each record type?



06         AI grammar review
           Is the capability approved, and if so, what endpoint, identity mechanism, data-handling rule, and model are authorized?



07         Change control and escalation
           What is the approved peer-review, release-validation, incident-response, and escalation process?




     POLICY BOUNDARY
     Until an authoritative answer is recorded, these items should remain explicitly marked as open and should not be presented as enforced system
     behavior.
