Connect a SharePoint Folder

Paste the URL of a SharePoint folder from your browser's address bar. PULSE CODE will use it as the project root. Each project can point to a different folder.

Copy the URL directly from your browser while viewing the folder in SharePoint.

Settings

SharePoint Connection

PULSE CODE connects to SharePoint using your existing browser session — no Azure AD registration or API keys needed. Upload PULSE-CODE.html to your SharePoint site's SiteAssets library and open it there. Add projects from the sidebar using any SharePoint folder URL.

Running locally?

Same-origin session auth only works when the page is hosted on SharePoint. Opening this file locally will show a connection error — that is expected.

Ask Sage AI

Enter your Ask Sage API key. Uses the OpenAI-compatible endpoint — just the key, no email needed. When connected to SharePoint, the key is stored in SiteAssets/pulse-code-config.json so it roams to all users automatically.

Found in your Ask Sage account settings. Saved to SharePoint (shared) + localStorage (local backup).
